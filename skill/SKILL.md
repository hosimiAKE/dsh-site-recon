# 网站深度侦察

一次侦察 = 一个问题 + 一套工作区账本。工具都读写同一个工作区，所以"读了什么、证据是什么、想清楚了没有"是同一份状态，不需要你另外记。

## 何时用

用户要你在网上搞清楚一件事，并且答案要**能分析**而不是一串链接：调研某个产品/公司/技术/政策、对比方案、做尽调、写报告。用户只要一条简单事实时不要用——直接查就好。

## 主循环

1. **立案** `recon_init` — 把用户原话作为 `question` 存进去，顺手定下宽度（来源角色）与预算。
2. **扫面** `recon_search` — 2–4 个**不同角度**的查询，专挑空着的来源角色打。
3. **读页** `recon_fetch` — 一次一页。先读最权威的那一页读完再回去搜；地图型站点先 `recon_map`。
4. **取证** `recon_evidence` — 只记页面里**逐字存在**的句子。工具会在快照里核对，找不到就拒收并回你最近的一段，照着改。
5. **立论** `recon_claim` — 一句话一条断言，挂上证据。状态由账本算：无证据 / 孤证 / 已支持 / 存疑。
6. **深挖** `recon_probe` — 对每条要写的断言过八级阶梯，答完再写。
7. **补漏** `recon_gaps` — 每读几页就调一次，它按"改动报告的程度"排序告诉你缺什么。
8. **成稿** `recon_report` → **过闸** `recon_audit` — 审计不通过就不算完成。

## 宽度：按角色，不按页数

"读了 20 个页面"不是宽度，"8 类来源各有实证"才是。默认八类：一手官方、技术文档、发布与路线、工程深潜、独立分析、社区摩擦、对照基线、量化数据。按题目换：医疗加法规，采购加价格条款，技术选型加竞品。

一个角色至少要有一页**真正读进来**的。只登记没读，覆盖率不算。

## 深度：八级阶梯

对每条断言问完这八级，答不上来的地方就是报告的边界：

| 级 | 问题 | 为什么关键 |
|---|---|---|
| 机制 | 输入什么、经过什么、输出什么 | 说不清机制 = 还没读懂 |
| 证据 | 哪一句原文支撑它 | 区分"提到过"与"说过这件事" |
| 前提 | 成立要什么条件、谁付成本 | 把宣传还原成交易 |
| 替代解释 | 还有什么解释同样成立 | 防止把相关当因果 |
| 反证 | 什么材料能推翻它 | 主动找反面，别等读者找 |
| 边界 | 什么情况下失效 | 适用范围就是可信度 |
| 二阶后果 | 会连锁引发什么 | 从"它是什么"到"它会带来什么" |
| 我方含义 | 对提问者意味着什么 | 报告的价值落点 |

经验：**机制**和**反证**最常改变结论。先答这两级。

## 三条硬规矩

**1. 断言不得大于证据。** 图注不能比画面说得更多，结论不能比引文说得更多。证据只支持 70%，就只写 70%，剩下 30% 放进"尚未回答"。宁可少一条发现，不要多一条站不住的发现。

**2. 先测量，再动作，再复测，最后才相信。** 你要描述的东西，先量它；动完再量一次；量到一致才落笔。截图、选段、引用都适用。猜出来的位置，写进报告就是错的。

**3. 一次一页，顺着页面自己的链接走。** 不做批量抓取：读一份、记一份、想清楚，再点下一个。页面上真实出现的链接比预先爬来的 URL 列表更接近这个站点的信息结构——你顺着它走，报告的结构自然就是这个领域的结构。

## 证据约定

- 每条证据一个编号 `E01`、`E02`……报告正文用 `【E01】` 引用，附录 A 给原文与链接。
- 证据分级：L1 一手原文 / L2 实测数据 / L3 独立来源 / L4 个体转述。全是 L4 的结论要自己说出来。
- 一条断言只有 1 个来源是"孤证"，要在正文注明。两条来源互相矛盾是"存疑"，要写出取舍理由（时间差？口径差？立场差？）。

## 常见故障与对策

| 现象 | 判断 | 对策 |
|---|---|---|
| 正文很短但 HTML 很大 | 前端渲染 | `recon_capture`，或换一个有服务端渲染的来源 |
| 403 / 人机校验 | 被墙 | 换来源；不要引用被墙页面的任何内容 |
| 截图目标被浮窗盖住 | 遮挡 | 换 `target` 或 `selector`，别硬拍 |
| 同一页两次文案不同 | A/B 轮换 | 以稳定段落/章节标题为锚点，别锚 H1 |
| 长页截图一片空白 | 懒加载 + 固定高度 iframe | 先滚到底触发加载，再逐屏拍 |
| 文档站滚不动 | 内部滚动容器 | 用 `recon_capture`，它按元素定位而不是整页 |

## 完成的定义

`recon_gaps` 没有 high、`recon_audit` 返回 PASS。两者都有时，报告里的"尚未回答"和"未覆盖来源"就是这份调研诚实的边界，把它留在报告里，不要删。

## 报告形状

方法与边界 → 来源地图 → 发现（每条带【E##】与深度分）→ 张力与不确定 → 对我们的含义 → 尚未回答 → 附录 A 证据、附录 B 来源。

读者应该能顺着任意一条发现，一路点到原文那一句。
